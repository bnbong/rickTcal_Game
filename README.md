# 선새임 몰래 춤추기

트릭컬 리바이브 비공식 팬게임입니다. 원작 트릭컬 리바이브의 저작권은 EPIDGames에 있습니다(ⓒ EPIDGames). 이 게임은 스토리 2부 1장 「빵점 공동체」의 역사 수업 장면에서 출발한 상황극이며, 브라우저에서 바로 실행됩니다.

수업이 너무나 지루한 에르핀은 당이 떨어져서 주말농장에 가기 직전, 선새임 몰래 춤을 추면 정말 재밌겠다는 생각을 하게 되는데..?

## 플레이 방법

- **춤추기:** 스페이스바(모바일에서는 화면의 춤 버튼)를 누르고 있는 동안 에르핀이 춤을 춥니다.
- **빵 먹기:** Z 키(모바일에서는 빵 버튼)를 누르면 죠안이 건넨 빵을 먹고 흥 게이지를 회복합니다. 한 판에 두 번 쓸 수 있습니다.
- **셰럼의 방향:** 셰럼이 화면 왼쪽(칠판)을 보면 안전하고, 오른쪽(학생들)을 보면 위험합니다. 오른쪽으로 돌기 직전에 느낌표 예고가 나타나므로 그때 춤을 멈춰야 합니다.
- **흥 게이지:** 안전할 때 춤을 추면 점수와 게이지가 오르고, 춤을 멈추면 게이지가 줄어듭니다. 게이지가 0이 되면 지루해서 쓰러집니다.
- **들킴:** 셰럼이 오른쪽을 보는 동안 춤을 추면 들켜서 게임이 끝납니다.
- **죠안:** 처음 60초 동안은 에르핀의 춤에 놀라 굳어 있다가, 이후에는 함께 춤을 춥니다. 죠안은 절대 들키지 않습니다.
- **기타:** P 또는 Esc 키로 일시정지할 수 있고, 최고 점수는 이 브라우저에 저장됩니다.

## 로컬 실행

Node.js와 npm이 필요합니다.

```bash
cd web
npm install
npm run dev
```

## 스크립트

`web/` 디렉터리에서 실행합니다.

| 명령 | 설명 |
| --- | --- |
| `npm run test` | Vitest로 게임 시뮬레이션 테스트를 실행합니다. |
| `npm run typecheck` | TypeScript 타입 검사를 실행합니다. |
| `npm run build` | 타입 검사 후 `dist/`에 정적 파일을 빌드합니다. |
| `npm run preview` | 빌드 결과를 로컬에서 미리 봅니다. |

## 에셋 파이프라인

게임에서 쓰는 이미지는 `web/public/assets/`에 들어 있으며 저장소에 포함되어 있습니다. 원화를 고쳤을 때만 다시 생성하면 됩니다.

```bash
python3 web/tools/build-assets.py
```

Pillow가 필요합니다(`pip install Pillow`). 입력은 `assets/concepts/2026-10-23/v4/retouched/upscaled-2x/`의 시트 이미지이고, 출력은 개별 스프라이트 PNG와 배경, `manifest.json`입니다.

## 배포

Cloudflare Workers의 정적 에셋 기능으로 배포합니다. 서버와 데이터베이스는 사용하지 않습니다. 설정은 `web/wrangler.jsonc`에 있습니다.

### Git 연동

Cloudflare 대시보드에서 Workers 프로젝트를 저장소와 연결하고 다음과 같이 설정합니다.

- 루트 경로: `web`
- 빌드 명령: `npm run build`
- 배포 명령: `npx wrangler deploy`
- 비프로덕션 브랜치 배포 명령: `npx wrangler versions upload` (미리보기 URL이 만들어집니다)
- 빌드 변수: `NODE_VERSION=22`

### CLI 수동 배포

처음 한 번 `npx wrangler login`으로 로그인한 뒤, `web` 디렉터리에서 `npm run deploy`를 실행합니다. 빌드 후 `dist`를 배포합니다.


## 참고 게임

고전 플래시게임 「선생님 몰래 춤추기」([소개 글](https://vidkidz.tistory.com/505))에서는 누르는 동안 춤추고 감시자가 돌아보면 멈추는 규칙만 참고했습니다. 원작의 화면, 음악, 효과음, 대사는 가져오지 않았습니다.

## 에셋과 권리 안내

- 그림은 GPT Image 2.5로 생성하고 같은 모델의 이미지 편집으로 리터칭한 뒤 FFmpeg로 가로·세로를 2배 업스케일했습니다.
- 효과음과 배경음악은 Web Audio API로 브라우저에서 합성하며, 외부 음원 파일을 쓰지 않습니다.
- 트릭컬 리바이브 공식 게임에서 추출한 이미지, 음원, 로고는 포함하지 않았습니다.
- 트릭컬 리바이브의 캐릭터와 설정에 대한 권리는 EPIDGames에 있습니다.
