# 캐릭터 원화 시트 및 2배 크기 출력물

현행 웹 게임의 캐릭터 스프라이트를 만드는 원화 시트와 배경·소품·UI 자료다. 세 캐릭터 시트는 초기 v4 생성본을 형태 기준으로 다시 그려 누적된 색 번짐과 자글거림을 정리했다.

## 파일과 상태

| 종류 | 이 폴더의 1배 파일 | 구현에 필요한 상태 |
| --- | --- | --- |
| 에르핀 | [erpin-poses.png](erpin-poses.png) | 좌상 기본(속눈썹 없는 흰 원형 눈 두 개, 작은 입), 우상 격한 춤, 좌하 빵 먹기, 우하 들킴(별 동공). 지팡이 없음 |
| 죠안 | [joanne-poses.png](joanne-poses.png) | 좌상 기본(붉은 눈), 우상 놀라 굳음(흰 눈·흰 땀), 좌하 함께 춤(**두 눈 모두 감음**), 우하 빵 건네기 |
| 셰럼 | [sherum-poses.png](sherum-poses.png) | 좌측 칸 칠판 보기·안전, 가운데 회전 예고(얼굴 옆 빨간 주의선 없음), 우측 칸 학생 보기·위험. **좌측 칸의 튀어나온 볼은 화면 왼쪽**. 머리·옷의 얼룩과 반점은 정리하고 외곽선의 손그림 느낌만 유지 |
| 배경 | [background-outdoors.png](background-outdoors.png) | 하늘·산·잔디의 빈 수업 배경 |
| 사물 | [props-sheet.png](props-sheet.png) | 긴 책상, 작은 책상, 접시 위 빵, 종이, 잉크병 |
| UI | [ui-sheet.png](ui-sheet.png) | 흥 게이지 외형, 빵·춤·일시정지 아이콘, 빈 라벨 |

화면 시안은 [기본](gameplay-idle.png), [초반 춤](gameplay-early-dance.png), [함께 춤](gameplay-later-dance.png), [빵 회복](gameplay-bread-recovery.png), [들킴](gameplay-caught.png) 순서로 확인한다. 이 이미지들은 이전 표정이 남아 있을 수 있는 **구도 참고용**이다. 현재 게임에 쓰는 얼굴과 선 품질은 위의 캐릭터 시트와 `web/public/assets/sprites/`의 개별 PNG를 따른다.

동일한 파일 이름의 [2배 크기 출력물](upscaled-2x/)도 있다. 투명 PNG는 가장자리의 색 번짐을 줄이도록 알파를 처리한 다음 크기를 늘렸다. 이는 **픽셀 수를 2배로 늘린 출력**이며, 없는 원화 디테일을 새로 복원한 초해상도 결과는 아니다. 원래 선의 크레파스 질감은 남겨 두었다.

## 구현 시 주의

- 캐릭터·사물·UI 시트는 투명하지만 **균일한 셀 크기의 애니메이션 아틀라스가 아니다**. 프레임별로 잘라 투명 여백, 기준점, 화면 크기를 맞춰야 한다. 각 포즈는 정지 원화이므로 난리부르스 춤의 다중 프레임 애니메이션은 추가 제작하거나 변형 연출해야 한다.
- 장면 시안에서 셰럼 얼굴이 포즈 시트와 조금 다르면 **수정된 셰럼 포즈 시트**를 따른다. 셰럼이 화면 왼쪽을 볼 때 안전, 오른쪽을 볼 때 위험이다.
- 흥 수치, 빵 사용 횟수, 점수와 글자는 코드로 그린다. 게이지 그림은 외형 참고이며 현재 채움 길이를 그대로 게임 상태로 쓰지 않는다.
- 브라우저 배포물에는 필요한 개별 포즈와 배경만 넣는다. 2배 크기 장면 시안 5장은 미리보기용이므로 게임 번들에 넣을 필요가 없다.
- 현재 웹 게임의 개별 PNG는 `web/tools/build-assets.py`로 이 폴더의 2배 시트에서 추출했다. 세 캐릭터의 모든 포즈를 `web/public/assets/sprites/`에 다시 반영했다.
