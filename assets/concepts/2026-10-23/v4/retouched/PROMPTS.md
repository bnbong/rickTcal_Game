# 리터칭 기록

모든 미술 리터칭은 기존 파일을 참조한 이미지 편집으로 진행했다. 공통 지시: **원래 포즈와 구도 유지, 흐릿한 색 경계와 탁한 번짐 정리, 제한된 팔레트·거친 크레파스 선·약한 종이 질감 유지, 새 요소 추가 금지**. 캐릭터·사물·UI 시트에는 진짜 투명 배경 유지도 지시했다.

- **셰럼:** 첫 번째 칠판 보기 포즈에서 튀어나온 볼 윤곽을 화면 왼쪽으로 옮기고 화면 오른쪽의 돌출을 정리. 세 포즈의 방향과 얼굴색 유지.
- **에르핀·죠안:** 기존 네 상태의 눈·입·의상·손·짧은 다리를 유지하며 윤곽과 채색 경계만 자연스럽게 정리. 에르핀 지팡이 금지, 흰 땀은 놀란 죠안에게만 허용.
- **화면 시안:** 원래 책상과 캐릭터 배치, 셰럼의 방향, 상태별 표정을 유지하며 번진 경계 리터칭. 함께 춤 장면은 죠안 포즈 시트의 좌하 상태를 추가 참조하여 붉은 눈·활짝 벌린 팔·다리와 휘날리는 의상으로 교체하고 흰 눈·땀을 제거.
- **배경·사물·UI:** 구름·산·잔디, 다섯 사물, UI 요소의 배치와 크기를 유지. 흐릿한 경계와 색 번짐을 정리하되 크레파스 결은 유지.

이미지 편집 출력은 원본과 거의 같은 픽셀 크기였다. 별도의 기술적 출력 단계에서 FFmpeg `spline` 보간으로 가로·세로를 각각 2배 늘렸다. 투명 시트에는 `format=rgba,premultiply=inplace=1,scale=iw*2:ih*2:flags=spline,unpremultiply=inplace=1,format=rgba` 필터를 적용해 투명 경계에서 어두운 색이 섞이는 문제를 줄였다. 배경과 화면 시안에는 `scale=iw*2:ih*2:flags=spline`을 적용했다.

## 2026-10-27 표정·효과 수정

- 에르핀 시트 좌상 기본 포즈: 화면 오른쪽 흰 눈의 바깥 위 속눈썹만 지우고 화면 왼쪽 눈처럼 매끈한 원형 윤곽으로 편집. 다른 포즈와 표정 유지.
- 죠안 시트 좌하 춤 포즈: 화면 왼쪽 눈은 감은 곡선, 오른쪽 눈은 열린 붉은 눈으로 윙크가 분명하게 읽히도록 편집. 나머지 상태 유지.
- 셰럼 시트 가운데 회전 포즈: 얼굴 화면 오른쪽의 빨간 주의선 세 개만 제거하고 해당 영역을 투명 처리. 리본 등 의상의 붉은색과 다른 두 포즈 유지.

세 시트의 2배 출력물을 다시 만들고, `web/tools/build-assets.py`로 웹용 개별 스프라이트를 재추출했다.

## 후속 수정: 두 눈을 감은 춤과 화질 정리

앞 절의 죠안 윙크는 요청을 잘못 해석한 결과였다. 초기 v4 생성본을 형태 기준으로, 당시 현행 시트를 색과 수정 조건의 참고로 사용하여 세 캐릭터 시트를 다시 만들었다. 공통 프롬프트는 `네 포즈/세 포즈의 배치와 의상 유지, 색 경계·외곽선의 번짐과 픽셀 자글거림 정리, 제한된 팔레트와 약한 크레파스 결 유지, 깨끗한 투명 알파`였다.

- **죠안:** 춤 포즈의 **두 눈을 모두 완전히 감은 곡선 눈매**로 지정했다. 붉은 홍채나 흰 눈동자가 춤 포즈에 나타나지 않아야 한다. 기본·빵 포즈는 붉은 눈, 놀란 포즈만 흰 눈과 땀을 유지한다.
- **에르핀:** 기본 포즈의 양쪽 흰 원형 눈에 속눈썹이 없고, 빵 먹기·춤·들킴 포즈와 짧은 다리·지팡이 없음은 유지한다.
- **셰럼:** 칠판 보는 첫 포즈의 볼 윤곽을 화면 왼쪽에 두고 가운데 포즈의 빨간 세 줄은 제거한다. 세 포즈의 복장과 얼굴을 일관되게 유지한다.

이미지 편집 도구는 2배 크기 입력도 1배 크기로 출력했다. 따라서 1배 시트를 정리된 원화 기준으로 저장하고, 2배 파일은 위에 기록한 알파 처리와 `spline` 보간으로 다시 내보냈다. 웹용 PNG는 이 2배 파일에서 추출했다.

## 셰렴 채색 얼룩 추가 정리

셰렴의 머리와 크림색 옷 내부에 남은 얼룩·반점·미세한 색 변화를 제거하도록 기본 이미지 편집 도구로 다시 편집했다. 색면은 균일한 기본색과 간단한 그림자로 정리하고, 크레파스 느낌은 외곽선에만 남겼다. 세 포즈의 방향·표정·의상과 가운데 포즈의 주의선 제거 조건을 유지했다.

[실제로 사용한 전체 프롬프트](sherum-color-cleanup.prompt.txt). 1배·2배 시트를 갱신하고 기존 추출 함수를 사용해 셰렴의 웹용 PNG 세 장과 매니페스트의 해당 크기만 갱신했다.
